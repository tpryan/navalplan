Typography

Primary Font: Raleway

Raleway is used for headings, branding, and buttons. It provides a clean, modern, yet sturdy nautical feel.

Heavy Weight (900) - Used for Buttons & Brand

Secondary Font: Lato

Lato is the primary body font. It is highly readable and works well for briefings, reports, and UI elements.

Buttons

Voyage Report Formats

The application provides comprehensive voyage reports in two distinct formats to balance aesthetic appeal with cross-platform compatibility.

1. Standard Web View

Designed for on-screen viewing within the application. Features rich visuals, interactive elements, and modern CSS effects.

  • Overview Grid: Responsive card-based layout (1-4 columns).
  • Interactive Charts: Dynamic tide and sun phase canvases.
  • Glassmorphism: Uses translucent backgrounds and blurs to maintain the app's aesthetic.
  • Media: Remote images and Material Symbols icons.

2. Clipboard-Optimized Format

A specialized transformation used when "Copy to Clipboard" is triggered. This ensures the report looks correct when pasted into Email, Word, or Notes.

  • Grid to Table: Converts CSS Grid cards into standard HTML <table> elements.
  • Style Flattening: Inlines critical styles and removes complex CSS like backdrop-filter.
  • Image Embedding: Converts remote images and canvases into data:base64 URIs.
  • Icon Stripping: Removes Material Symbols (which often render as text strings like "radar" in other apps) and replaces them with whitespace or simple text.
