# Cyber-Tech Design System
 
## Core Philosophy
This design system is built for a high-energy, futuristic user experience. It leverages a deep-space dark mode foundation with high-contrast, vibrant accents to guide user attention and define a technical, forward-thinking aesthetic.
 
## Visual Language
 
### Color Palette
*   **Neutral Foundation:** The interface uses `#0A111A`, a deep charcoal-navy, as the primary surface color to reduce eye strain and provide a canvas for vibrant elements.
*   **Primary Accent:** `#00E5FF` (Electric Cyan) serves as the main interactive color, used for primary calls-to-action and key indicators.
*   **Supporting Accents:** 
    *   `#FF7043` (Deep Orange) is utilized for secondary interactions and highlighting secondary information.
    *   `#FFCA28` (Amber) provides a warm tertiary highlight for badges, alerts, or decorative flair.
 
### Typography
The system employs a dual-font strategy to balance character with functionality:
*   **Headlines:** **Space Grotesk** brings a geometric, tech-focused personality to the system’s hierarchy.
*   **Body & Labels:** **Manrope** provides a highly legible, modern sans-serif experience for all functional text and UI labels, ensuring clarity at all sizes.
 
## UI Geometry & Spatial Rhythm
*   **Roundedness:** A value of `2` (Moderate) is applied to all components. This creates a balance between sharp professionalism and modern accessibility, avoiding the harshness of 90-degree angles while maintaining a structured feel.
*   **Spacing:** A value of `2` (Normal) defines the layout density. This provides a standard industrial rhythm that balances information density with comfortable white space, suitable for professional tools and dashboards.
 
## Component Specifications
*   **Buttons:** High-contrast backgrounds using primary/secondary hex codes with dark text or white text depending on accessibility requirements.
*   **Surfaces:** Layers are defined by subtle variations of the neutral base, maintaining the "vibrant" dark-mode theme.
*   **Interactions:** Hover and focus states should leverage the primary electric cyan to provide clear feedback.
